# 训练自己的 LoRA

这个目录是训练脚手架。模型权重和数据集**不进 git** —— 只有脚本和配置在这里。

```
training/
  README.md            ← 你在读的这份（数据规格 + 操作步骤）
  prepare_dataset.py   ← 校验 / 缩放 / 生成 caption，输出 kohya 目录结构
  sdxl_lora.toml       ← SDXL LoRA 训练配置
  train_pod.py         ← 起 RunPod 训练 pod，训完把 LoRA 存到网络卷
```

## 一、图片 LoRA（SDXL / lustify）

训练目标：让模型**默认**画出你要的男性解剖比例，不再依赖提示词技巧。

### 数量

| 张数 | 效果 |
|---|---|
| < 15 | 过拟合，会把背景、模特长相一起学进去 |
| **25–40** | **推荐区间** |
| > 60 | 收益递减，训练时间翻倍 |

### 每张图的硬性要求

- **分辨率**：短边 ≥ 1024px。低于这个数细节会糊，训出来的 LoRA 也糊
- **格式**：JPG / PNG，不要截图、不要带水印、不要有平台 logo
- **画质**：真实照片或高质量渲染。**不要**用 AI 生成的图当训练集 —— 会把现有模型的缺陷一起学进去
- **目标部位清晰可见、无遮挡**：这是整个训练的目的，被手/衣物挡住的图没有价值
- **一张图一个人**：多人同框会让模型学不清主体

### 整个数据集的多样性要求（比单张质量更重要）

**唯一应该保持一致的是「比例」，其他一切都要变。** 否则 LoRA 会把不该学的东西一起学走：

| 维度 | 要求 | 不这么做的后果 |
|---|---|---|
| 姿势 | 站 / 跪 / 坐 / 躺 / 侧身，各 5–8 张 | 只会生成那一个姿势 |
| 景别 | 全身为主，半身少量 | 构图被锁死 |
| 模特 | **至少 5–8 个不同的人**，不同发色肤色体型 | 会把某个人的脸学进去（严重问题） |
| 场景 | 室内 / 室外 / 纯色背景混合 | 背景永远是同一个房间 |
| 光线 | 自然光 / 影棚光 / 暖光 | 色调被锁死 |
| 角度 | 正面 / 侧面 / 微俯 / 微仰 | 只会出一个机位 |

**一句话检验：把 30 张图摆一起，除了「比例」这一条，你应该说不出第二条共同点。**

### 素材从哪来（按推荐顺序）

1. **自己拍 / 委托拍摄** —— 版权最干净，能精确控制比例标准。有模特发布协议（model release）就能商用无忧
2. **购买有授权的成人素材库** —— 部分成人内容制作方提供带 AI 训练授权的图包，签合同时要写明「允许用于机器学习训练」
3. **购买单个创作者的授权** —— 直接联系符合你审美标准的内容创作者买使用权，价格通常比素材库低

**必须避开的**：
- ❌ 直接爬 Pornhub / X / Reddit / Tumblr —— 有版权，商用有法律风险
- ❌ **可辨认的真人**（明星、网红、任何未授权的具体个人）—— LoRA 会学到那张脸，等于生成深度伪造，这是刑事风险不是民事风险
- ❌ 无法确认年龄的素材 —— 只用有明确 18+ 记录的来源，这条没有商量余地
- ❌ AI 生成的图（包括我们自己生成的）—— 会固化现有缺陷

**给你的实操建议**：先按上面第 3 条走。找 5–8 个比例符合你标准的创作者，每人买 4–6 张授权，凑够 30 张，成本可控且版权链条清楚。

### 打标（caption）

`prepare_dataset.py` 自动生成，规则是：**描述除了「要学的概念」之外的一切**。

```
mhprop, a muscular blonde man kneeling on a white rug, bright living room, natural light
        └─ 触发词           └─ 这些都要写清楚，好让模型知道「这些不是我要学的」
```

**不要**在 caption 里描述比例本身 —— 没被描述的共性才会被吸收进触发词。这是打标最反直觉也最关键的一条。

### 运行

```bash
python training/prepare_dataset.py --src <你的图片文件夹> --out training/dataset --trigger mhprop
```

```bash
python training/train_pod.py --dataset training/dataset --name mhprop-v1
```

## 二、视频 LoRA（Wan 2.2 I2V-A14B）

**先别急着训。** 视频端已经有现成的：[lopi999/Wan2.2-I2V_General-NSFW-LoRA](https://huggingface.co/lopi999/Wan2.2-I2V_General-NSFW-LoRA)（6 万下载，基座正是我们用的 A14B，触发词 `nsfwsks`）。

要注意它是**两个文件**：`NSFW-22-H` 和 `NSFW-22-L` —— A14B 是双专家 MoE，高噪声和低噪声专家各挂各的，只挂一个会失效。

**顺序建议**：先测这个现成的，不够再训自己的。省一笔钱和一周时间。

### 如果确实要训，数据规格

| 项 | 要求 |
|---|---|
| 数量 | 30–60 个片段 |
| 时长 | **每段 2–5 秒**（太长显存爆，太短学不到运动） |
| 分辨率 | ≥ 720p，16:9 或 9:16 统一 |
| 帧率 | 统一到 16fps（Wan 的原生帧率） |
| 内容 | **一个片段一个连续动作**，不要有剪辑切换 |
| 稳定性 | 镜头别晃。手持晃动会被学成「抖动」 |
| 多样性 | 同上：动作一致，人物/场景/光线都要变 |

视频素材来源和图片同理,而且更严格 —— 视频的版权和肖像权追责更常见。**强烈建议走委托拍摄或买断授权**，不要用爬来的片段。

### 成本预估

| | 时间 | 费用 |
|---|---|---|
| 图片 LoRA（30 张） | 30–60 分钟 | < $1 |
| 视频 LoRA（40 段） | 6–12 小时 | $8–20 |
