# 训练自己的 LoRA

这个目录是训练脚手架。模型权重和数据集**不进 git** —— 只有脚本和配置在这里。

```
training/
  README.md            ← 你在读的这份（数据规格 + 操作步骤）
  prepare_dataset.py   ← 校验 / 缩放 / 生成 caption，输出 kohya 目录结构
  sdxl_lora.toml       ← 训练配置
  train_pod.py         ← 起 RunPod 训练 pod，训完把 LoRA 存到网络卷
```

---

## 训练基座：Chroma1-HD（已确认）

不是 SDXL。Chroma 在训练层面就包含解剖概念，实测三个种子用朴素提示词全部正确，
而 SDXL 需要提示词技巧且换种子会失败。

**这决定了素材要求**：你不需要再为「补基础解剖」收集素材，
只需要「比例符合你的审美标准」的样本。所以数量比原计划少。

---

## 一次只训一个概念

把「比例」「双人构图」「玩具」混在一个 LoRA 里，训出来的是一锅粥 —— 
每个概念都学得不彻底，而且互相污染。分开训，按下面的顺序。

| 顺序 | LoRA | 张数 | 解决什么 |
|---|---|---|---|
| **1（现在做）** | 男性比例 / 审美 | **15–25** | 现在生成的比例不符合你的标准 |
| 2（可选） | 双人构图 | 20–30 | 多人同框是图像模型最容易崩的场景 |
| 3（可选） | 玩具 / 道具 | 15–25 | 特定道具的外观和佩戴位置 |

---

## LoRA #1：男性比例 —— 素材清单

### 数量

**15–25 张。** 少于 12 张会过拟合（把某个人的脸学进去），多于 30 张收益递减。

### 每张图必须满足

| 项 | 要求 | 为什么 |
|---|---|---|
| 分辨率 | **短边 ≥ 1024px** | 低于此细节糊，训出来的 LoRA 也糊 |
| 来源 | **真实照片** | AI 生成图会把现有缺陷一起学进去 |
| 目标部位 | **清晰、无遮挡、无裁切** | 被手/衣物挡住的图对这个 LoRA 零价值 |
| 人数 | **单人** | 多人会让模型学不清主体（双人留给 LoRA #2） |
| 画质 | 无水印、无平台 logo、非截图、对焦准 | 水印会被当成特征学进去 |
| 格式 | JPG / PNG | — |

### 整个数据集的多样性（比单张质量更重要）

> **唯一该一致的是「比例」。把 20 张摆一起，你应该说不出第二条共同点。**

| 维度 | 具体要求 |
|---|---|
| **模特** | **至少 5–8 个不同的人**，不同发色、肤色、体型 ⚠️ 最重要 |
| 姿势 | 站 / 跪 / 坐 / 躺 / 侧身，每种 3–5 张 |
| 状态 | **勃起与非勃起都要有**，否则模型只会一种状态 |
| 角度 | 正面 / 侧面 / 微俯 / 微仰 |
| 景别 | 全身为主，半身少量 |
| 场景 | 室内 / 室外 / 纯色背景混合 |
| 光线 | 自然光 / 影棚光 / 暖光 |

### 可以直接发给创作者的话术

> 需要 20 张男性人体参考照片，用于 AI 模型训练（商用）。要求：
> 短边 1024px 以上原图、无水印、单人、全身入镜且下体清晰无遮挡；
> 需要 5 位以上不同模特，站/跪/坐/躺姿势各若干，勃起与非勃起状态都要；
> 需签署允许「用于机器学习训练及商业用途」的授权书与模特发布协议。

### 素材来源（按推荐顺序）

1. **委托拍摄** —— 版权最干净，能精确指定比例标准，含模特发布协议
2. **向单个创作者买授权**（最实际）—— 找 5–8 位比例符合你标准的创作者，
   每人买 3–5 张，天然满足「多模特」要求，版权链条清楚
3. **有 AI 训练授权的成人素材库** —— 合同里必须写明「允许用于机器学习训练」

### 必须避开（是风险，不是建议）

- ❌ 爬 Pornhub / X / Reddit —— 有版权，商用会被追责
- ❌ **可辨认的真人**（明星、网红、任何未授权个人）—— LoRA 会学到那张脸，
  产出等同深度伪造，这是刑事风险
- ❌ 年龄无法确认的素材 —— 只用有明确 18+ 记录的来源，没有商量余地
- ❌ AI 生成图（包括本站生成的）—— 会固化现有缺陷

## 视频 LoRA：**现在不要收集素材**

视频 LoRA 训在 Wan 2.2 上，教的是「怎么动」，和图片 LoRA 是两件事。

**但要先验证需不需要。** Wan 2.2 基座可能靠提示词就能做出你要的动作 ——
上一次为 Wan NSFW LoRA 做同样的验证，结论是基座够用，省下了整套素材成本。

**验证顺序**：先用提示词实测「单人动作 / 双人互动 / 玩具互动」三类，
不够再训。视频素材的采集成本远高于图片，不该在验证前投入。

### 如果验证后确实要训，规格如下

| 项 | 要求 |
|---|---|
| 数量 | 30–60 个片段 |
| 时长 | **每段 2–5 秒**（太长显存爆，太短学不到运动） |
| 分辨率 | ≥ 720p |
| 帧率 | 统一 16fps（Wan 的原生帧率） |
| 内容 | **一段一个连续动作，不能有剪辑切换** |
| 镜头 | **固定机位，不能晃** —— 手持抖动会被学成「抖动」 |
| 多样性 | 动作一致，人物/场景/光线都要变 |

视频的肖像权和版权追责比图片更常见，**强烈建议走委托拍摄或买断授权**。

## 你准备好之后

图片放进一个文件夹，把路径给我。我会先跑校验：

```bash
python training/prepare_dataset.py --src <你的文件夹> --out training/dataset --trigger mhprop
```

它会检查分辨率、揪出近似重复、警告构图单一，**不合格就拒绝生成数据集** ——
这些毛病只有训练完才看得出来，而那时候钱已经烧了。
